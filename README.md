# Live Shortcut Cheat Sheet

**Version 2.0 — A free, multilingual Ableton Live 12 shortcut reference for Max for Live.**

Find the shortcut you need without leaving Ableton Live. Live Shortcut Cheat Sheet puts **328 keyboard shortcuts and navigation commands** into a searchable floating window, with Windows and macOS key combinations, nine interface languages, and a layout that adapts to the window size.

## Highlights of v2.0

- **328 shortcuts** across 10 categories, based on Ableton Live 12 shortcut documentation.
- **Nine languages:** English, Japanese, Simplified Chinese, Korean, Spanish, French, German, Portuguese, and Italian.
- **Multilingual instant search:** look up commands using translated terms, English names, categories, or key combinations, regardless of the selected interface language.
- **Fully responsive shortcut cards:** the number of columns changes automatically with the floating window's width. There is no fixed three- or four-column limit.
- **Windows / macOS reference:** show both platforms together or filter to one platform.
- **Adjustable text size:** 12–24 px, with responsive card sizing.
- **Compact 169 × 169 px Device View:** a single **OPEN** button, inspired by the OSTF Producer layout.
- **Automatic floating window:** opens when the device loads and can be reopened with **OPEN**.
- **Single `.amxd` file:** the interface and shortcut data are embedded; no separate files or internet connection are required.

## Installation

1. Download **`Live_Shortcut_Cheat_Sheet_v2.0.amxd`** from this repository.
2. Drag the `.amxd` file into an audio-effect device chain in Ableton Live (for example, on the Master track).
3. The floating reference window should open automatically. Choose your language on the initial screen.
4. Search for a command, filter by category or platform, and resize the window or adjust the text size as needed.
5. If you close the window, click **OPEN** in Device View to show it again. You can change the language from the floating window at any time.

**Tip:** Search using the action you want to perform, rather than trying to remember its category. You can also search by keyboard shortcut.

## Requirements and notes

- Designed for **Ableton Live 12 with Max for Live**.
- Windows and macOS shortcut combinations are included; this does not by itself confirm testing on both operating systems.
- Actual shortcut behavior can depend on your Live version, operating system, keyboard layout, and active editor or mode.
- The device passes audio through unchanged and does not modify your music or clips.
- The floating interface and the shortcut catalog are bundled in one `.amxd` file.
